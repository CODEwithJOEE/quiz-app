# 🚀 Getting Started

## Para sa Lahat ng Users

### Paano Mag-login

1. Buksan ang app link na binigay ng school mo
   - Example: `https://quiz.yourschool.com`
2. I-enter ang **email** at **password** na binigay ng admin o teacher mo
3. Tap **"Sign In"**

**Note:** Walang "Sign Up" button — ang account mo ay ginawa ng admin o teacher. Kung wala kang account, kontakin sila.

### Paano Mag-install sa Phone (Recommended)

Ang app ay gumagana sa browser, pero **mas maganda kung naka-install** — mas mabilis at may fullscreen mode.

#### Sa Android (Chrome):

1. Buksan ang app link
2. Tap ang menu (⋮) sa taas
3. Tap **"Install app"** o **"Add to Home screen"**
4. Tap **"Install"**
5. Lalabas ang icon sa home screen mo

#### Sa iPhone (Safari):

1. Buksan ang app link sa **Safari** (dapat Safari, hindi Chrome)
2. Tap ang **Share** button (⎋) sa ilalim
3. Scroll down → tap **"Add to Home Screen"**
4. Tap **"Add"**
5. Lalabas ang icon sa home screen

**Bakit importante i-install?**

- Mas mabilis mag-open
- Fullscreen mode (walang browser controls)
- Mas secure sa quiz-taking (mas mahirap mag-switch ng app)

### Mga Roles

| Role            | Ano'ng kaya nilang gawin                                                        |
| --------------- | ------------------------------------------------------------------------------- |
| **Super Admin** | Gumawa ng teachers at students, manage lahat ng users                           |
| **Teacher**     | Gumawa ng rooms, mag-invite ng students, gumawa ng quizzes, mag-check ng scores |
| **Student**     | Sumali sa rooms via invitation, mag-take ng quizzes, makita scores              |

### Navigation

Sa ilalim ng screen may **bottom navigation** — ito ang paraan mo para lumipat ng pages:

- 🏠 **Home** — Dashboard, invitations, quick actions
- 🚪 **Rooms** — Lahat ng rooms mo
- 📋 **Quiz** — Lahat ng quizzes (student), o quiz list ng room (teacher)
- 👤 **Profile** — Account info, logout

_(Ang teachers at admins ay may extra nav items — Students at Users.)_

### Paano Mag-logout

1. Tap **Profile** sa bottom nav
2. Scroll down → tap **"Log Out"**
3. Confirm

### Dark Mode

Kung naka-dark mode ang phone mo (Settings → Display → Dark), automatic na sumusunod ang app.

## Troubleshooting

**Hindi ako makapag-login**

- I-check ang spelling ng email
- Ensure tama ang password (case-sensitive)
- Kung nalimutan ang password, kontakin ang admin/teacher mo para i-reset

**Wala akong makitang room**

- Kung student ka, kailangan mo munang **i-accept ang invitation**
- Puntahan ang **Home** page → hanapin ang "Room Invitations" section
- Tap "Accept"

**Hindi lumalabas ang app icon**

- Sa iPhone, dapat Safari ang gamitin (hindi Chrome)
- Sa Android, dapat Chrome (hindi Firefox)
- Try i-restart ang browser at subukan ulit

**Nag-freeze yung quiz**

- Huwag i-close ang app
- I-refresh ang browser (pull down)
- Kung hindi pa rin, kontakin ang teacher mo — naka-save ang progress mo
