# 🚀 Getting Started

Base guide para sa lahat ng users.

---

## Paano Mag-login

1. Buksan ang app link: `https://your-app.vercel.app` (o ang custom domain ng school mo)
2. I-enter ang **email** at **password** na binigay ng admin o teacher
3. Tap **"Sign In"**

**⚠️ Note:** Walang "Sign Up" button. Ang account mo ay ginawa ng admin o teacher. Kung wala kang account, kontakin sila.

---

## Paano Mag-install sa Phone

Ang app ay gumagana sa browser, pero **mas maganda kung naka-install** — mas mabilis at may fullscreen mode.

### Android (Chrome):

1. Buksan ang app link sa Chrome
2. Tap ang menu (⋮) sa taas
3. Tap **"Install app"** o **"Add to Home screen"**
4. Tap **"Install"**
5. Lalabas ang icon sa home screen

### iPhone (Safari):

1. Buksan ang app link sa **Safari** (⚠️ hindi Chrome)
2. Tap ang **Share** button (⎋) sa ilalim
3. Scroll down → tap **"Add to Home Screen"**
4. Tap **"Add"**
5. Lalabas ang icon sa home screen

### Bakit Importante I-install?

- ✅ Mabilis mag-open (parang native app)
- ✅ Fullscreen mode — walang browser controls
- ✅ Mas secure sa quiz-taking (mas mahirap mag-switch ng apps)
- ✅ Auto-update

## Navigation

Sa ilalim ng screen may **bottom navigation**:

| Icon | Label        | Function                              |
| ---- | ------------ | ------------------------------------- |
| 🏠   | **Home**     | Dashboard, invitations, quick actions |
| 🚪   | **Rooms**    | Lahat ng rooms mo                     |
| 📋   | **Quiz**     | Quiz listing (teachers & students)    |
| 🎓   | **Students** | (Teacher only) Manage students        |
| ⚙️   | **Users**    | (Admin only) Manage all users         |
| 👤   | **Profile**  | Account info, dark mode, logout       |

**Note:** Ang nakikita mong nav items ay depende sa role mo.

---

## Roles & Permissions

| Role            | Pwedeng gawin                                                    |
| --------------- | ---------------------------------------------------------------- |
| **Super Admin** | Gumawa ng lahat ng users, manage system                          |
| **Teacher**     | Gumawa ng rooms, students, quizzes; mag-check ng scores          |
| **Student**     | Sumali sa rooms via invitation; mag-take ng quiz; makita results |

---

## Paano Mag-logout

1. Tap **Profile** sa bottom nav
2. Scroll sa pinakailalim
3. Tap **"Log Out"**
4. Confirm

---

## Dark Mode

Ang app ay may **dark mode** support:

1. Puntahan ang **Profile** page
2. Sa **"Appearance"** section, pumili:
   - **Light** — Light theme
   - **Dark** — Dark theme
   - **System** — Auto (sumusunod sa phone settings)

Ang preference mo ay naka-save sa device mo.

## Common Issues

**Hindi ako makapag-login**

- I-check ang email spelling
- Password is case-sensitive
- Kung nalimutan, kontakin ang admin/teacher

**Wala akong makitang room**

- Kung student: kailangan mo munang **i-accept ang invitation**
- Puntahan ang **Home** page → hanapin ang "Room Invitations"

**Hindi lumalabas ang app icon**

- iPhone: dapat **Safari** ang gamitin (hindi Chrome)
- Android: dapat **Chrome** (hindi Firefox)
- Try i-restart ang browser

**Nag-freeze habang nag-take ng quiz**

- Huwag i-close ang app
- I-refresh ang browser (pull down)
- Naka-save ang progress mo
- Kung hindi pa rin, kontakin ang teacher

**Naka-terminate ako sa quiz**

- Check ang **Result page** para makita ang reason
- Common: nag-switch ng tab 3 times
- Kontakin ang teacher kung may dispute

---

## Tips

- **I-install ang app** bago mag-exam
- **I-charge ang phone** bago mag-take
- **I-connect sa stable WiFi** o mobile data
- **I-DND ang phone** habang nag-take (para hindi ma-flag ang notifications)
- **I-close ang ibang apps** para smooth ang quiz-taking
